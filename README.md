# FashionFlex -- E-commerce Web Application

FashionFlex is a full-featured fashion e-commerce platform built with
Spring Boot, integrating secure authentication, real-time payment, and a
complete shopping experience for users. The system includes both
user-facing features and a full admin dashboard for management.

## Tech Stack

### Frontend

-   HTML5, CSS3
-   Bootstrap 5
-   JavaScript ES6+
-   jQuery 3.x
-   Thymeleaf 3.1.x

### Backend

-   Java 21 (LTS)
-   Spring Boot 3.5.7
-   Spring Data JPA
-   Spring Security
-   MySQL 8+
-   Redis 6+ (caching)
-   Maven
-   Lombok
